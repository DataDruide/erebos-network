Quick-Start

1. i2pd installieren

Lade den I2P-Router herunter und starte ihn auf 127.0.0.1:7070.

i2pd.website

2. Erebos starten

Klone das Repo und starte den Daemon auf 127.0.0.1:9050.

python -m erebos_network --serve

3. .erebos nutzen

Öffne http://my-service.erebos im Erebos-Browser.

Über Erebos

Erebos ist ein anonymer Browser für das I2P-Netzwerk. Er basiert auf Firefox ESR 128 und kombiniert die Fingerprint-Härtung des Tor Browsers mit der dezentralen Architektur von I2P.
